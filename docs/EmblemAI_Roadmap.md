## Daily Startup Checklist

-   Activate `.venv`
-   `git pull` (if collaborating or switching machines)
-   Read sprint objective
-   Start coding

## Daily Shutdown Checklist

-   `git add .`
-   `git commit -m "Meaningful message"`
-   `git push`
-   Update sprint journal

## Key Concepts

-   **Git** tracks project history.
-   **GitHub** stores a remote copy for collaboration.
-   **.venv** isolates this project's Python packages.
-   **requirements.txt** records project dependencies so others can
    install the same packages.
